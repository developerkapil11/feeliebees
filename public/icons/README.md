# Social brand icons

Instagram, Facebook, Pinterest, and YouTube SVGs come from the [Simple Icons project](https://github.com/simple-icons/simple-icons), distributed under CC0. Source vectors are retained in this directory; the same paths are rendered inline by `components/social-icon.tsx` so they inherit the site's colour and scale cleanly.

- https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/pinterest.svg
- https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/youtube.svg
